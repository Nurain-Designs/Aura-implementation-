# Aura UI Design 🌌

A premium, high-performance architectural UI design system built with React, Vite, and Framer Motion. This project showcases a sophisticated design aesthetic featuring "Neural Architecture," "Quantum Encryption," and "Precision Engineering."

## 🚀 Local Development

To run the project locally, click the link below:

### [👉 Launch Local Server](http://localhost:5173)

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 7](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons/Utilities**: [Lucide React](https://lucide.dev/), `clsx`, `tailwind-merge`

## ✨ Key Features

- **Premium Aesthetics**: Dark-mode primary design with gold accents and high-end typography.
- **Micro-Animations**: Smooth transitions and scroll-based animations using Framer Motion.
- **Responsive Layout**: Optimized for all devices with an architectural grid structure.
- **Cursor Glow**: Interactive custom cursor tracking.
- **Scroll Progress**: Visual feedback for long-page scrolling.
- **Marquee**: Dynamic enterprise-grade feature display.

## 📦 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Dev Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

## 📂 Project Structure

- `src/components`: UI components (Hero, Architecture, Systems, etc.)
- `src/utils`: Utility functions (cn, etc.)
- `public/images`: High-quality assets for the UI.
